# Support

[繁體中文](SUPPORT.zh.md) · **English**

## Before asking

1. Read the [FAQ](docs/en/faq.md) and [troubleshooting guide](docs/en/troubleshooting.md).
2. Check the repository's Issues tab — search by the exact error code
   (`10102`, `80009`, `disallowed_useragent`).
3. Reproduce once with a clean session and copy the **log lines only**. Remove
   tokens, email addresses, school names, and book titles.

## Where to ask

| Topic | Channel |
|---|---|
| Reproducible bug | Issues → New issue → **Bug report** |
| Feature idea / scope question | Issues → New issue → **Feature request** |
| Documentation problem | Issue with the `docs` label, or a pull request |
| Security vulnerability | [SECURITY.md](SECURITY.md) — private reporting only |
| Conduct report | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

The repository may enable GitHub Discussions. If it is enabled, use
**Q&A** for setup questions and **Ideas** for proposals. If it is not, use an
issue with the closest template.

## What we can help with

- Installing and running the three builds
- Interpreting an error code or a log line
- Reproducing a bug on web, Android, or Windows
- Correcting documentation or adding a translation
- Reviewing a protocol claim against the public Swagger document or the
  decompiled client excerpts

## What we cannot help with

- Recovering an account, resetting a password, or appealing a ban — contact SJRC
  or your school.
- Obtaining books, DRM keys, or decrypted content.
- Bypassing quotas, authentication, or access controls.
- Google Cloud project configuration for the official app.
- Guaranteeing that automated reading is permitted by your institution. Ask your
  school and read the platform's terms.

## Response expectations

This is a volunteer project. There is no SLA. A good report with a clear
reproduction is likely to get attention first. Issues with no reproduction steps
and no version information may be closed after 14 days.

## Private contact

For conduct reports and other non-security private matters, open a minimal issue
asking for a private contact route. Do not include personal or account data in
the public issue.
