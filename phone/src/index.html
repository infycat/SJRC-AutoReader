01 · 電郵登入

正在載入 Google 登入…
GIS 載入— 頁面 origin— User-Agent— One Tap— 帳號回呼尚未收到 帳號— pre-login— token—
點按鈕 → Google 彈出帳號選擇器 → 選好帳號後自動回傳 id_token（credential）， 直接送 POST /v1/public/accounts/users/google/pre-login {providerId, type}， 全程不用手動貼任何東西。
錯誤 400：invalid_request / doesn't comply with Google's OAuth 2.0 policy = 你用了「Android 應用程式」類型的 Client ID 去跑網頁流程，Google 會直接封鎖。 解法：改用 Web 應用程式 類型的 Client ID（已預設填好），並把上面類型設成 web。
GIS 只認已授權的 JS origin：直接開 file:// 會失敗。用 python3 -m http.server 8080 起本機服務、開 http://localhost:8080/sjrc-autoread.html， 並把該 origin 加進 Google Cloud Console → OAuth client → Authorized JavaScript origins。
密碼會先 base64 再送出，與原版 App 相同。
ticket 狀態—
ticket 是什麼：pre-login 成功後伺服器發的一次性憑證， 代表「這個人已經過了密碼/Google 那一關，現在等你輸入驗證碼」。 驗證碼必須配 ticket 才知道是哪一筆登入，所以兩者缺一不可。
不需要 ticket 的情況：密碼登入若直接回 accessToken，就已完成登入， 完全不用碰驗證碼。
